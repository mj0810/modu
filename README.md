# 모두의 길 v2 — 대전 서구

가상 예시를 실제 OpenStreetMap 등록 데이터로 교체한 정적 웹사이트입니다.
API 키·Node 설치·빌드 없이 실행할 수 있습니다.

## 실행

`index.html`을 Chrome 또는 Edge에서 열거나, 이 폴더에서
`python -m http.server 8765 --bind 127.0.0.1` 실행 후
http://127.0.0.1:8765 에 접속합니다. 지도 배경은 인터넷이 필요합니다.

## GitHub와 Vercel에 적용

1. ZIP을 풀고 **index.html이 있는 폴더의 내용**을 GitHub `mj0810/modugil` 저장소의 최상위에 업로드합니다. ZIP 파일 자체를 올리지 않습니다.
2. `index.html`, `app.js`, `styles.css`, `data` 폴더, `vercel.json`을 함께 올려야 합니다. `data` 안의 파일은 폴더 구조를 유지합니다.
3. Vercel 프로젝트의 Root Directory를 비웁니다. 이 저장소는 하위 폴더를 지정하지 않습니다.
4. Framework Preset: Other, Build Command: Override를 켜고 빈칸, Output Directory: `.`(마침표 하나).
5. 최신 GitHub 커밋으로 재배포하고 Visit으로 확인합니다. `vercel.json`에도 동일한 정적 사이트 설정이 들어 있습니다.

## 수록 데이터

- 범위: OSM에 등록된 대전광역시의 서구 행정경계.
- 지도 데이터 기준: 2026-11-27, 수집 시점은 `data/facilities.json`의 `collectedAt`.
- 77개 지도 객체: 엘리베이터 16, 화장실 25, 경사로 포함 통로 20, 이름이 등록된 휠체어 접근 시설 16.
- 같은 시설의 입구·통로가 여러 지도 객체로 등록될 수 있습니다. 시설·건물 77곳의 중복 없는 공식 집계가 아닙니다.
- 이 중 60개는 원본에 이름이 없고 75개는 주소가 없습니다. 이름·주소를 지어내지 않고 미등록으로 표시합니다.
- 장애인 화장실 또는 휠체어 접근 가능 여부를 추정하지 않습니다. 일반 화장실은 별도로 구분됩니다.
- 경사로는 `ramp=yes` 태그를 사용합니다. 계단에 설치된 자전거용 경사로일 수도 있으므로 휠체어 이동을 보장하지 않습니다.
- 이름이 있는 시설의 `wheelchair=yes`는 해당 시설의 등록값이며, 특정 내부 편의시설 존재를 뜻하지 않습니다.
- 길·건물·영역의 좌표는 대표 좌표입니다. 출입구나 승강기 탑승 지점과 다를 수 있습니다.
- 학교·사유 시설·제한 출입 시설도 있을 수 있습니다. 원본 출입 조건을 함께 확인해야 합니다.
- 실시간 고장·운영 상태, 현장 검증, 경로 안내, 공용 사용자 제보는 구현하지 않았습니다.
- 제보 대신 브라우저 한정 고장 메모를 제공합니다. 24시간 유효, 5분 중복 제한, 삭제 가능.

## 갱신

Python 3 환경에서 `python fetch_osm.py`를 한 번 실행합니다.
서구 경계로 제한한 Overpass 조회 결과를 저장하고 브라우저용 데이터를 다시 생성합니다.
API 오류·빈 응답이면 기존 원본을 덮어쓰지 않습니다.
공개 Overpass 서버를 이용자 접속마다 호출하지 않습니다. 사이트는 수집본을 표시하므로 자동 갱신되지 않습니다.
수집 후 변경된 `data` 폴더를 GitHub에 올리고 재배포해야 반영됩니다.

브라우저에서 시설 목록 로드, 종류 필터, 휠체어 이용 가능 필터, 상세 정보,
고장 메모 저장·중복 방지·삭제를 확인했습니다. 실제 위치 권한 허용은 사용자 브라우저에서 확인해야 합니다.
